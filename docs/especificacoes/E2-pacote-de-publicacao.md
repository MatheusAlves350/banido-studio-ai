# E2. Pacote de publicação com botões "Copiar"

> Documento de especificação. Nenhum código foi alterado. Origem: proposta de 25/11/2026, frente E.

## 1. Problema

**Analogia:** é como uma caixa de montagem com as peças separadas e etiquetadas. Hoje as peças estão espalhadas em várias telas.

Título, descrição, tags, capítulos e miniatura estão em lugares diferentes da interface. O usuário precisa procurar e copiar cada um.

## 2. Objetivo

Uma tela final, "Pacote de publicação", com cada item em um bloco:
1. **Título**, com contador de caracteres (B4).
2. **Descrição**, com botão copiar.
3. **Tags**, com botão copiar.
4. **Capítulos**, com botão copiar (C5).
5. **Miniatura**, quando existir (B6).
6. Botão **"Copiar tudo"** com a ordem certa para colar.

## 3. Regras

- A publicação continua **manual**, sem API do YouTube, conforme decidido pelo Matheus.
- Nada é enviado a lugar nenhum.

## 4. Riscos

Baixo. Depende de B4 para o contador e de C5 para os capítulos.

## 5. Estimativa

- **Esforço:** baixo (2 dias). **Risco:** baixo.
